# Origin and public boundary

The source experiment used AutoGen roles to clarify a project request, propose a file tree, map dependencies, write per-file prompts, validate the plan, and assemble a handoff. It also loaded a local `.env`, fixed the model to a dated GPT-4 configuration, started from one hard-coded Discord/Wordle example, and trusted model-produced path headings.

This public continuation preserves the staged agent idea while replacing provider coupling, hard-coded project input, and unsafe path materialization. The original `.env` and raw transcript/output material are excluded. The current repo runs entirely offline unless a future caller deliberately supplies a networked runner.
